# Driftix User Guide

## Getting Started

### Installation

1. Clone the repository
2. Install dependencies:

   ```bash
   npm install
   ```

3. Set up environment variables:

   ```bash
   cp .env.example .env
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

### Authentication

- Sign up with email and password
- Or use social login (Google, GitHub, Twitter, Facebook)
- Reset password if needed
- Enable 2FA for additional security

## Troubleshooting

### Common Issues

1. Login Problems
   - Check internet connection
   - Verify credentials
   - Clear browser cache
   - Try password reset

2. Theme Issues
   - Clear browser cache
   - Check browser compatibility
   - Verify theme settings

3. Performance Issues
   - Check internet connection
   - Clear browser cache
   - Update browser
